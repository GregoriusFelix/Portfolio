# Portfolio (Astro starter)

## Run it
    npm install
    npm run dev        # http://localhost:4321

## Add a project
Copy `src/content/work/sample-project.md`, rename it, edit the frontmatter and text. It appears on the homepage automatically.

## Deploy (Netlify or Cloudflare Pages)
Push to GitHub, connect the repo, build command `npm run build`, output directory `dist`.

## Where to edit
- Your name / email: BaseLayout.astro, Navbar.astro, index.astro
- Colors and fonts: src/styles/global.css
- Page sections: src/pages/
